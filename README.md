📝 Опис проєкту

Даний проєкт є програмним комплексом для автоматизованого аналізу зображень електрокардіограм (ЕКГ) з метою класифікації діагностичних ознак. Система розроблена як допоміжний інструмент для лікарів первинної ланки, студентів-медиків та дослідників.

В основі системи лежить гібридний підхід, що поєднує методи комп'ютерного зору для попередньої обробки зображень та класичні моделі машинного навчання для їх класифікації на основі інтегральних ознак (площ), утворених відхиленням сигналу від ізолінії.
✨ Ключові можливості

    Багатоетапний конвеєр обробки зображень: Автоматичне очищення зображень ЕКГ від шумів та артефактів (сітка, текст, лінії посилення).

    Виділення інтегральних ознак: Перетворення графічних даних у числовий вектор зі 160 ознак, що описують площі відхилення сигналу.

    Класифікація за допомогою ML.NET: Використання навченої моделі на базі алгоритму LightGBM для класифікації ЕКГ на чотири діагностичні категорії.

    Візуалізація результатів: Генерація обробленого зображення з нанесеними базовими лініями та розрахованими площами.

    Клієнт-серверна архітектура: Система складається з серверного API та прототипу мобільного клієнта.

🛠️ Технологічний стек

Система повністю розроблена в екосистемі .NET.

    Мова програмування: C# 12 (.NET 9.0.302)

    Серверна частина: ASP.NET Core Web API

    Мобільний клієнт (прототип): .NET MAUI

    Обробка зображень:

        OpenCvSharp: для складних операцій комп'ютерного зору (бінаризація, морфологія, пошук контурів, in-painting).

        SixLabors.ImageSharp: для базових операцій з зображеннями (завантаження, збереження, малювання).

    Машинне навчання:

        ML.NET: для навчання та інтеграції моделі.

        LightGBM: як основний алгоритм класифікації.

📂 Структура репозиторію

Репозиторій містить три основні проєкти:

    ECG_API: Основний проєкт. Серверна частина, що реалізує всю логіку обробки та прогнозування.

    EcgDataGenerator: Консольна утиліта для автоматичної обробки вихідного датасету зображень та генерації .csv файлу з ознаками.

    EcgModelTrainer: Консольна утиліта для навчання, оцінки та збереження моделі машинного навчання на основі згенерованого .csv файлу.

    (Опціонально) Mobile_ECG_M: Прототип мобільного клієнта на .NET MAUI.

🚀 Як запустити та використовувати
Вимоги до середовища

    .NET SDK 9.0.302

    IDE (JetBrains Rider або Visual Studio 2022)

Запуск API

    Відкрийте файл рішення ECG_API.sln.

    Встановіть ECG_API як стартовий проєкт (Startup Project).

    Переконайтеся, що файл навченої моделі EcgClassifier.zip знаходиться у папці ECG_API/MLModel/ і має властивість Copy to Output Directory: Copy if newer.

    Запустіть проєкт (F5). Відкриється Swagger UI.

    Використовуйте ендпоінт POST /api/analysis/analyze для тестування, завантажуючи зображення ЕКГ.

Генерація датасету та навчання моделі

    Підготовка даних:

        Відкрийте EcgDataGenerator/appsettings.json та вкажіть правильні шляхи до вашого вихідного датасету та куди зберегти .csv файли.

        Встановіть EcgDataGenerator як стартовий проєкт і запустіть його.

    Навчання моделі:

        Відкрийте EcgModelTrainer/Program.cs та вкажіть шлях до згенерованого .csv файлу.

        Встановіть EcgModelTrainer як стартовий проєкт і запустіть його.

        Нова модель EcgClassifier.zip буде збережена. Скопіюйте її у проєкт ECG_API.
