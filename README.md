Програмний комплекс для автоматизованого аналізу зображень електрокардіограм (ЕКГ) та класифікації діагностичних ознак. Проєкт розроблено в рамках магістерської кваліфікаційної роботи.

Автор: Мельник Д.Р.
Науковий керівник: Мельник Р. А.
Опис проєкту
Система є допоміжним інструментом для лікарів первинної ланки, що дозволяє отримувати швидку попередню класифікацію зображень ЕКГ. В основі лежить гібридний підхід, що поєднує:

    Комп'ютерний зір (OpenCV) для багатоетапної попередньої обробки та очищення зображень.

    Інженерне виділення ознак на основі унікального методу розрахунку інтегральних площ.

    Класичне машинне навчання (ML.NET) для класифікації отриманого вектору ознак.
Ключові можливості

    Автоматичне очищення зображень: Видалення сітки, текстових артефактів, ліній посилення та стартового імпульсу.

    Виділення 160 інтегральних ознак: Перетворення графічних даних у числовий "відбиток" ЕКГ.

    Високоточна класифікація: Використання навченої моделі на базі LightGBM для розпізнавання 4 діагностичних категорій.

    Генерація візуалізацій: Створення обробленого зображення з нанесеними базовими лініями та розрахованими площами.

    Клієнт-серверна архітектура: Система складається з RESTful API та прототипу мобільного клієнта.
Архітектура
Серверна частина побудована на основі чистої архітектури (Clean Architecture) та принципів SOLID. Це забезпечує слабку зв'язаність, високий рівень тестованості та легкість подальшого розширення.

    Core: Ядро системи. Містить інтерфейси сервісів та доменні моделі.

    Infrastructure: Містить конкретні реалізації для роботи з OpenCV, ML.NET, файловою системою тощо.

    Presentation (API): Шар ASP.NET Core, що приймає запити та оркеструє роботу сервісів.

Інструкція по запуску та використанню
Для роботи API потрібен навчений файл моделі EcgClassifier.zip. Щоб його створити, виконайте наступні кроки:
а) Генерація датасету

    Відкрийте проєкт EcgDataGenerator.

    Налаштуйте шляхи до вихідних зображень та куди зберегти CSV-файли у файлі appsettings.json.

    Встановіть EcgDataGenerator як стартовий проєкт і запустіть. У вказаній папці будуть згенеровані .csv файли з ознаками.

б) Навчання моделі

    Об'єднайте згенеровані .csv файли в один dataset_combined.csv.

    Відкрийте проєкт EcgModelTrainer.

    Вкажіть шлях до dataset_combined.csv у файлі Program.cs.

    Встановіть EcgModelTrainer як стартовий проєкт і запустіть.

    Нова модель EcgClassifier.zip буде збережена. Скопіюйте її у папку ECG_API/MLModel/.

2. Запуск API

    Відкрийте файл рішення ECG_API.sln.

    Встановіть проєкт ECG_API як стартовий (Startup Project).

    Переконайтеся, що для файлу ECG_API/MLModel/EcgClassifier.zip встановлено властивість Copy to Output Directory: Copy if newer.

    Запустіть проєкт (F5). Відкриється Swagger UI.

    Використовуйте ендпоінт POST /api/analysis/analyze для тестування, завантажуючи зображення ЕКГ.

Навчена модель продемонструвала високу ефективність на відкладеній тестовій вибірці, досягнувши загальної точності класифікації 96%. Детальний аналіз результатів, метрик та конвеєра обробки представлено у пояснювальній записці до магістерської кваліфікаційної роботи.
